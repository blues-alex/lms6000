## Обзор проекта [Readme_EN](./Readme.md)

Проект `lms6000` представляет собой библиотеку для взаимодействия с прибором LMS6000, предназначенным для измерения спектральных характеристик света.  Библиотека предоставляет функциональность для отправки команд прибору, получения данных измерений и настройки параметров.

**Основные компоненты:**

*   **`SerialDevice` Interface:**  Определяет интерфейс для взаимодействия с последовательным портом.  Это позволяет использовать различные реализации последовательного порта (например, реальный последовательный порт, mock для тестирования).
*   **`LMS6000` Struct:**  Представляет прибор LMS6000 и содержит информацию о текущих настройках (например, время усреднения).
*   **Команды:**  Набор констант, представляющих собой байтовые последовательности, используемые для отправки команд прибору.
*   **`Meassure` Struct:**  Структура для хранения результатов измерений, включающая карты значений и спектральных данных.

**Используемые библиотеки и фреймворки:**

*   `encoding/binary`:  Для преобразования данных между различными форматами (например, uint32 в байты).
*   `fmt`:  Для форматированного ввода/вывода.
*   `math`:  Для математических операций, в частности, для преобразования float32.
*   `time`:  Для работы со временем.
*   `github.com/blues-alex/clog`: Для логирования.

## Файл `lms6000.go`

### `package lms6000`

Объявление пакета, содержащего код библиотеки.

### `import (...)`

Импортирует необходимые пакеты.

### `const (...)`

Определяет константы, используемые в проекте.

*   `DATA_OFS`: Смещение данных измерений в байтовом представлении ответа прибора.
*   `TIMEDATE_OFS`: Смещение информации о дате и времени в байтовом представлении ответа прибора.
*   `DATA_LENGTH`: Длина данных измерений в байтовом представлении ответа прибора.
*   `HALLO_MESS`:  Команда приветствия прибору.
*   `START_MEASSURE`:  Команда запуска одиночного измерения.
*   `START_MULTI_MEASSURES`: Команда запуска измерения в многоканальном режиме.
*   `GET_DATA`:  Команда запроса данных измерений.
*   `SET_TIME_AVERAVE`: Команда установки времени усреднения.
*   `GET_TIME_AVERAVE`: Команда запроса текущего времени усреднения.
*   `MEASSURE_KEYS`:  Массив строк, представляющих названия измеряемых параметров.

### `type Meassure struct`

Определение структуры `Meassure`, которая содержит результаты измерений.

*   `Values`:  Карта, содержащая значения измеряемых параметров (например, PAR, PPFD).  Ключи - названия параметров, значения - измеренные значения.
*   `Spectrum`:  Карта, содержащая спектральные данные.  Ключи - индексы спектральных каналов, значения - измеренные значения.

### `type SerialDevice interface`

Определение интерфейса `SerialDevice`, который определяет методы для взаимодействия с последовательным портом.

*   `Write([]byte) (int, error)`:  Отправляет данные на последовательный порт.  Возвращает количество отправленных байтов и ошибку (если произошла).
*   `ReadMessage() ([]byte, error)`:  Читает данные с последовательного порта.  Возвращает прочитанные байты и ошибку (если произошла).
*   `Close() error`: Закрывает соединение с последовательным портом.

### `func NewLMS6000(device SerialDevice) (*LMS6000, error)`

Конструктор для создания экземпляра `LMS6000`.

*   **Параметры:**
    *   `device`:  Реализация интерфейса `SerialDevice`.
*   **Возвращаемые значения:**
    *   `*LMS6000`:  Указатель на созданный экземпляр `LMS6000`.
    *   `error`:  Ошибка (если произошла).
*   **Описание:**
    *   Создает новый экземпляр `LMS6000`, инициализирует его `device` и `TimeAverage`.
    *   Получает текущее время усреднения с прибора и устанавливает его в структуре `LMS6000`.

### `func (l *LMS6000) GetTimeAverage() (time.Duration, error)`

Получает текущее время усреднения с прибора.

*   **Параметры:** Нет.
*   **Возвращаемые значения:**
    *   `time.Duration`:  Текущее время усреднения.
    *   `error`:  Ошибка (если произошла).
*   **Описание:**
    *   Отправляет команду `GET_TIME_AVERAVE` на прибор.
    *   Читает ответ прибора.
    *   Преобразует полученные данные в `time.Duration`.

### `func (l *LMS6000) SetTimeAverage(t time.Duration) error`

Устанавливает время усреднения на приборе.

*   **Параметры:**
    *   `t`:  Новое время усреднения.
*   **Возвращаемые значения:**
    *   `error`:  Ошибка (если произошла).
*   **Описание:**
    *   Преобразует `time.Duration` в uint32.
    *   Отправляет команду `SET_TIME_AVERAVE` на прибор, вместе с данными о новом времени усреднения.
    *   Читает ответ прибора.

### `func (l *LMS6000) GetMeassure() (*Meassure, error)`

Выполняет измерение и возвращает результаты.

*   **Параметры:** Нет.
*   **Возвращаемые значения:**
    *   `*Meassure`:  Структура, содержащая результаты измерения.
    *   `error`:  Ошибка (если произошла).
*   **Описание:**
    *   Запускает измерение с помощью `StartMeassure`.
    *   Делает паузу на время усреднения.
    *   Отправляет команду `GET_DATA` на прибор.
    *   Читает ответ прибора.
    *   Парсит полученные данные и создает структуру `Meassure`.

### `func (l *LMS6000) SwithToMultiMeassureMod() error`

Переключает прибор в многоканальный режим измерения.

*   **Параметры:** Нет.
*   **Возвращаемые значения:**
    *   `error`:  Ошибка (если произошла).
*   **Описание:**

    *   Читает ответ прибора.

### `func (l *LMS6000) StartMeassure() error`

Запускает одиночное измерение.

*   **Параметры:** Нет.
*   **Возвращаемые значения:**
    *   `error`:  Ошибка (если произошла).
*   **Описание:**
    *   Отправляет команду `START_MEASSURE` на прибор.
    *   Читает ответ прибора.

Преобразует массив байтов в массив float32.

*   **Параметры:**
    *   `buf`:  Массив байтов.
*   **Возвращаемые значения:**
    *   `[]float32`:  Массив float32.

### `func newMeassure() *Meassure`

Создает новый экземпляр структуры `Meassure`.

*   **Параметры:** Нет.
*   **Возвращаемые значения:**
    *   `*Meassure`:  Указатель на созданный экземпляр `Meassure`.
*   **Описание:**
    *   Инициализирует карты `Values` и `Spectrum` в структуре `Meassure`.

### `func parseMeassure(m []byte) *Meassure`

Парсит байтовый массив, полученный от прибора, и создает структуру `Meassure`.

*   **Параметры:**
    *   `m`:  Байтовый массив, полученный от прибора.
*   **Возвращаемые значения:**
    *   `*Meassure`:  Структура, содержащая результаты измерения.
*   **Описание:**
    *   Извлекает данные измерений и спектральные данные из байтового массива.
    *   Заполняет карты `Values` и `Spectrum` в структуре `Meassure`.

## Примеры использования

```go
// Создание экземпляра LMS6000
lms, err := NewLMS6000(myPort)
if err != nil {
   // Обработка ошибки
}

// Получение данных измерения
measure, err := lms.GetMeassure()
if err != nil {
   // Обработка ошибки
}

// Вывод результатов
fmt.Println(measure.Values)
fmt.Println(measure.Spectrum)

// Установка времени усреднения
err = lms.SetTimeAverage(10 * time.Second)
if err != nil {
   // Обработка ошибки
}
```
